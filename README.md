# RF配線プランナー

無線モジュール・RF部品・アンテナの配置と、同軸/USB/DCケーブルの配線を計画するWebツール(pure HTML/JS, no build)

ブラウザで `index.html` を開くだけで動作します。サーバー・ビルド・外部ライブラリは不要です。

**▶ ブラウザでそのまま試す: https://kijitora-no-hito.github.io/RF_Module_Plannner/**

[eSportsEvent_FloorPlanner](https://github.com/kijitora-no-hito/eSportsEvent_FloorPlanner) をベースに、電子工作・無線機器向けに作り直したものです。

## 主な機能

- **部品・機器の配置**: アンテナ / RF部品 / リファレンスクロック / 機器・モジュール / 電源 の5分類で31種を収録。移動・90°回転・サイズ変更・名前変更に対応
- **コネクタ嵌合チェック**: 各ポートはコネクタの系統(SMA / RP-SMA / U.FL / N / BNC / USB-A / USB-C / microUSB / DC / LAN)とオス・メスで管理。以下のような接続を防ぐ
  - オス同士・メス同士の接続
  - SMA と RP-SMA の取り違え
  - 給電側どうし・受電側どうしの電源接続
  - クロック出力どうしなど、信号出力どうし・信号入力どうしの接続
- **自動配線(直交ルーティング)**: ケーブルは部品を避けながら直角に曲がって配線される。平行するケーブルは重ならないよう隣の線へずらし、交差する箇所は後から引いたケーブルが半円でまたぐ
- **直結**: アンテナのSMAオスを機器のSMAメスへ直接挿すなど、ケーブルを介さない接続
- **ケーブル長の算出**: 配線経路に沿った長さ(cm)を計算し、市販の標準長さ(10/15/20/30/50cm, 1/1.5/2/3/5/10m)から推奨長さを提示
- **必要部品・ケーブルリスト**: 配置した部品とケーブルを数量・推奨長さ付きで集計。テキストコピー可
- **電源未接続の警告**: 受電ポートに何も接続されていない機器に ⚡ を表示
- **カスタム部品の登録**: ポートごとにコネクタ・役割名(IN/OUT等)・配置辺・給電方向・信号方向を指定できる。既存部品の複製編集にも対応
- **保存**: localStorage への自動保存と、JSONファイルのエクスポート/インポート

## 操作

| モード | キー | 操作 |
|---|---|---|
| エリア作成 | `1` | 筐体・ベース板などの外形をグリッド点クリックで作図。`Enter` / 始点クリックで確定 |
| 配置 | `2` | パレットから選択してクリック配置。ドラッグ移動、`R` で回転、右下ハンドルでサイズ変更、`Delete` で削除、ダブルクリックで名前変更 |
| 接続 | `3` | パレットでケーブルを選択し、緑枠のポートを2つクリック。ケーブルをクリックして `Delete` で削除 |

- ズーム: マウスホイール、またはツールバーの `＋` / `－`
- パン: ホイール押し込みドラッグ、または `Space` + ドラッグ
- 1グリッド = 1cm(100%表示時)。ズームに応じて 0.25cm〜4cm に切り替わる
- ポートの表示: 塗りつぶしの丸がオス(プラグ)、中央が白い丸がメス(ジャック)。マウスを乗せるとコネクタの詳細を表示

## 収録部品

| 分類 | 部品 |
|---|---|
| アンテナ | ホイップアンテナ(SMA) / GPSアンテナ(アクティブ) / 無線LANアンテナ(RP-SMA) |
| RF部品 | RFスプリッター(SMA×3) / T型分岐 抵抗なし(F-F-F・M-F-F) / T型分岐 抵抗あり(抵抗分配器) / RFバイアスティー(SMA×2) / RFバイアスティー(DC入力付) / LNA / バンドパスフィルタ / アッテネータ / SMA中継アダプタ(F-F) |
| リファレンスクロック | OCXO(10MHz) / GPSDO / ルビジウム発振器 / クロック分配アンプ(1→4) |
| 機器・モジュール | GPSモジュール(SMA + USB-C) / SDR受信機 / SDR送受信機(REF/PPS入力付) / LoRaモジュール / 無線LANアダプタ / ESP32開発ボード(U.FL) / NanoVNA / Raspberry Pi / PC / USBハブ(バスパワー・セルフパワー) |
| 電源 | USB電源アダプタ / モバイルバッテリー / DC電源アダプタ |

ケーブル: 同軸 SMA-SMA / SMA延長 / RP-SMA / SMA-RP-SMA / U.FLピグテール / SMA-N / SMA-BNC / USB A-C / C-C / A-microB / USB延長 / USB-DC電源 / DC延長 / LAN / 直結

## 構成

```
├── index.html
├── css/style.css
└── js/
    ├── constants.js    # コネクタ・ケーブル種別、嵌合・給電方向ルール
    ├── templates.js    # 部品テンプレート定義
    ├── geometry.js     # スナップ・ポート座標・ケーブル長計算
    ├── routing.js      # 直交ルーティング(A*)・重なり回避・交差のジャンプ描画
    ├── state.js        # 状態管理・保存
    ├── render.js       # SVG描画
    ├── palette.js      # パレットUI・カスタム登録
    ├── checklist.js    # 必要部品・ケーブルリスト
    ├── interactions.js # マウス/キーボード操作
    └── main.js         # 初期化・ズーム/パン
```

部品を追加するときは `js/templates.js`、コネクタやケーブルを追加するときは `js/constants.js` を編集します。
